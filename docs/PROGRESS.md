# Прогресс EduKit frontend

Обновляется после каждого этапа. Общий план и backend — `edukit-backend/docs/PROGRESS.md` и `docs/BACKLOG.md`.

## Этап 00 — фундамент (25.11.2026)

**Статус:** реализован и проверен локально, включая совместную проверку с API; CI ещё не запускался (нет GitHub-репозитория).

### Сделано

- Next.js 16.4.6 + React 19.3 + TypeScript strict + Tailwind 4 + shadcn/ui; точные версии, `package-lock.json`, Node 24.
- Языки kk/ru/en: маршрут `[locale]`, выбор языка по `Accept-Language`, переключатель с сохранением страницы, словари с одинаковым набором ключей, формат KZT.
- Дизайн-токены Ocean Blue для светлой и тёмной темы, радиус ≤ 4 px, Noto Sans с казахскими буквами, переключатель темы (светлая/тёмная/системная).
- Страницы: публичная (описание, утверждённые цены без обещаний по кредитам, вопросы), дизайн-система, состояние системы (данные из API, состояние ошибки), фирменная 404.
- Состояния loading/empty/error/offline/success/forbidden; ссылка «Перейти к содержанию»; видимый фокус.
- Типизированный клиент API из `contracts/openapi.json` (копия OpenAPI backend).
- Защитные заголовки, CI (lint, typecheck, unit, build, E2E, Gitleaks, npm audit), AGENTS.md, CLAUDE.md, `.claude/skills`, `.claude/agents`, копия ТЗ (SHA-256 `b1b3ce7e…7c07`, совпадает с backend).
