# Дизайн-система Ocean Blue

Источник значений — [src/app/globals.css](../src/app/globals.css). Живой пример — страница `/{locale}/design`. Контраст токенов проверяет [tests/unit/contrast.test.ts](../tests/unit/contrast.test.ts).

## Принципы

- Строгие прямоугольники: радиус 0–4 px. Тонкие рамки и общие границы вместо карточек с тенями.
- Сетка 4/8 px. Фирменная фактура — «тетрадь в клетку» (класс `.squared-paper`), используется дозированно: один раз на экран.
- Цвет не единственный носитель смысла: состояние всегда подписано текстом и иконкой.
- Выравнивание по левому краю, строки до ~75 символов (`max-w-prose`).
- Анимации минимальны; при `prefers-reduced-motion` отключаются. В режиме высокой контрастности (`forced-colors`) фактура убирается.

Все пары «текст/фон» ≥ 4.5:1, границы полей и фокус ≥ 3:1 (WCAG 2.2 AA) — проверено тестом для обеих тем. Светло-синий #60A5FA не используется для мелкого текста на светлом фоне (контраст 2.5:1).

## Типографика

Noto Sans (`next/font`, наборы latin + cyrillic + cyrillic-ext). Казахские буквы Ә Ғ Қ Ң Ө Ұ Ү Һ І проверяются E2E-тестом на странице дизайн-системы. Заголовки — жирное начертание с плотным трекингом; основной текст 16–18 px.

## Логотип

Текстовый: «Edu» цветом текста + «Kit» цветом `primary`.

## Состояния

Компоненты `StatePanel` (empty, error, offline, success, forbidden) и `LoadingPanel` (скелетон + текст для экранного диктора). Ошибки объясняют, что случилось и что делать, и дают действие восстановления.

## Открыто

Точные токены, onboarding и итоговый выбор шрифта — UX-проверка с преподавателями (ТЗ §14 P1).
