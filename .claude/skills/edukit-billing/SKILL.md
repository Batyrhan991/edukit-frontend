# edukit-billing

## Практические инструкции

1. Бери планы, цены и квоты из утвержденного каталога. Сохраняй суммы целыми в единицах, заданных контрактом провайдера, с явной валютой.
2. Выдавай доступ по подтвержденному серверному событию или сверке с провайдером. Проверяй подпись webhook, ожидаемую валюту и сумму, связь с заказом и уникальность события.
3. Определи переходы подписки, срок доступа после отмены и правила возврата по продуктовой спецификации. Сохраняй время и источник перехода для аудита и сверки.
4. Учитывай кредиты проводками с ID операции. Атомарно резервируй лимит и закрывай резерв при успехе или освобождай по согласованной политике. Сверяй зависшие резервы.
5. Отрабатывай интеграцию в тестовой среде провайдера. Для реального приема платежей сначала подтверди доступность интеграции и готовность аккаунта владельца.

## Критерии приемки

- [ ] Один подтвержденный платеж активирует доступ один раз даже при повторе и изменении порядка доставки событий.
- [ ] В тестовой среде проверены ошибки оплаты, отмена и согласованный сценарий возврата.
- [ ] Параллельные AI-запросы соблюдают лимит, а баланс сверяется с проводками.
