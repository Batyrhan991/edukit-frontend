# edukit-games

## Практические инструкции

1. Веди каталог 14 игр по утвержденному списку. Для каждого доступного ID зафиксируй учебную цель, правила, состояния раунда, критерий окончания, подсчет очков и словари. При отсутствии перечня оставь состав каталога открытым.
2. Отдели общие комнаты, участников и таймеры от механики игры. SignalR передает команды и состояния, сервер проверяет принадлежность к комнате, фазу, ответы и начисляет очки.
3. При переподключении проверь членство и верни авторизованный снимок с версией. Повторная отправка команды использует тот же ID, а запоздалый ответ обрабатывается по серверному дедлайну.
4. Держи правильные ответы на сервере до фазы раскрытия. Храни итог один раз на сессию и используй псевдонимы либо минимально необходимые данные в рейтингах.

## Критерии приемки

- [ ] Для полного запуска все 14 ID сверены со спецификацией и проходят сценарий от входа до результата.
- [ ] Два клиента видят одинаковый счет после переподключения и повторной отправки.
- [ ] Доступ к событиям и состоянию комнаты ограничен ее участниками и уполномоченными ролями.
