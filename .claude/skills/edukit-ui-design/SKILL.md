# edukit-ui-design

## Практические инструкции

1. Используй существующие токены Ocean Blue. При их отсутствии предложи согласуемые семантические токены для фона, текста, акцента, границ, фокуса и статусов.
2. Построй экран вокруг задачи роли. Например, учителю в журнале нужны контекст класса, состояние публикации и действия по оценке, а ученику нужна собственная обратная связь.
3. Опиши состояния компонентов, клавиатурный порядок, фокус после закрытия диалога и текстовые альтернативы действиям с иконками. Дублируй смысл цветового статуса подписью.
4. Проверь длинные переводы kk, ru и en, переносы и масштабирование. Для игр и редакторов предусмотрены доступные альтернативы жестам там, где сценарий это позволяет.

## Критерии приемки

- [ ] Интерактивные элементы проходят сценарий с клавиатуры и имеют видимый фокус.
- [ ] В обычном тексте проверено отношение контраста 4,5:1 или выше, для крупного текста 3:1 или выше.
- [ ] Ключевые состояния видимы на узком и широком экране во всех трех локалях.
