# edukit-devops

## Практические инструкции

1. Обеспечь воспроизводимую локальную среду для Next.js, ASP.NET Core и PostgreSQL. Подключай Redis и другие сервисы по требованиям сценария и текущей архитектуре.
2. В CI раздели сборку, проверки типов, тесты и упаковку. Используй зафиксированные зависимости и продвигай один проверенный артефакт между средами.
3. Определи порядок миграций, проверки готовности и условия остановки выпуска. Для отката учитывай совместимость старого приложения с новой схемой.
4. Настрой структурированные журналы и метрики для REST, SignalR, задержки AI, расходов и фоновых задач. Оформи запуск восстановления БД и файлов в отдельной среде.
5. Перед production-выпуском проверь доступность хостинга и регионов, сроки хранения резервных копий и секреты по конфигурации среды. Выполняй production-действия только в рамках явно запрошенного релиза.

## Критерии приемки

- [ ] Из чистой копии проекта поднимается локальная среда по документированным командам.
- [ ] В staging пройдены миграция, проверка после деплоя и упражнение по восстановлению.
- [ ] Для релиза есть проверяемые версии артефактов и измеряемые условия остановки или отката.
