# edukit-database

## Практические инструкции

1. Определи владельца записи, жизненный цикл, обязательные поля и ограничения. Для данных организаций отрази принадлежность в запросах и там, где возможно, в ограничениях связей.
2. Добавляй уникальность для бизнес-инвариантов, например попытки после финализации или обработанного внешнего события. Защиту от конкуренции привяжи к используемой транзакции или версии записи.
3. Ревьюй миграцию EF Core и SQL. Для рискованных преобразований сначала добавь совместимую схему, затем перенеси записи, проверь полноту и только после перехода потребителей убери старую структуру.
4. Проверяй планы типичных запросов журналов, участников и списков документов на данных сопоставимого масштаба. Согласуй индексы с фильтрами и сортировкой.

## Критерии приемки

- [ ] Миграция проходит на чистой БД и на копии предыдущей схемы с синтетическими данными.
- [ ] Конкурентная операция сохраняет инварианты и корректные связи организаций.
- [ ] Для изменения с риском потери данных описан и проверен путь восстановления.
