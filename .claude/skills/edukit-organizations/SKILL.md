# edukit-organizations

## Практические инструкции

1. Раздели учетную запись, членство в учреждении и назначение на классы. Сверь допустимые роли и переходы с требованиями проекта.
2. Составь матрицу действий для администратора учреждения, учителя и ученика. Ограничь учителя назначенными классами по утвержденным правилам и определяй доступ по актуальным членствам.
3. Сохраняй приглашение с ролью, организацией, временем истечения и одноразовым состоянием. При принятии проверяй адресата и согласованность целевых классов. Создавай членство атомарно.
4. Соблюдай жизненный цикл класса и учетной истории при переводе, отзыве роли и архивировании. Любая смена активной организации требует проверки членства на сервере.

## Критерии приемки

- [ ] Приглашение дает доступ только назначенной роли и области, а повтор принятия не дублирует членство.
- [ ] Проверены перевод ученика, отзыв учителя и переключение между двумя организациями.
- [ ] Архивирование сохраняет исторические работы и оценки по установленным правилам видимости.
